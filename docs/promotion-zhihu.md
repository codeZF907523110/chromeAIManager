## 正文

### 一、每个 Chrome 重度用户都经历过的下午

这些瞬间，你肯定也熟：

- 标签页开到 60 多个，Chrome 内存占用 8G，风扇起飞。想清理，但逐个检查「这个待会儿还看不看」，比清理本身还累；
- 书签栏几百条收藏，全是「hi」「新建文件夹(2)」，想整理，拖了两条就放弃了；
- 明明记得上周看过一篇讲 XX 的文章，历史记录搜关键词，翻了三页没找到；
- 想批量关闭某个网站的页面、想把同一域名的标签归成一组、想把工作标签和摸鱼标签分开——单看每一件都是小事。

单看每一件都是小事，但每一件都值得装一个专门的小插件——直到你的扩展栏，变成了第二排标签页。

市面上的 AI 浏览器插件，大多只做一件事：**陪你聊天**。选中文字问 AI、总结一下网页——本质还是「网页内容的旁观者」。

但我想要的是能真正**动手干活**的那种：我说一句「把没用的标签关了，剩下的按网站分好组」，它就去关、去分组。于是自己写了一个——

**「AI 浏览器管家」（AI Browser Commander）**，一个 Chrome 侧边栏 AI 助手。今天开源，给大家介绍一下它能干什么。

### 二、它不是聊天机器人，是操作工

打开插件，右边弹出侧边栏，里面是一只叫**塔比（Tabby）**的小猫助手（名字来自虎斑猫 Tabby，也是「标签页 Tab」的谐音）。

> 📷 **【截图 1 位置】侧边栏全貌**
> 截什么：插件打开状态下的完整侧边栏，最好正处于一段对话中（有塔比的回复）
> 怎么截：随便跟它聊两句（比如「你是谁」），截取整个侧边栏区域

你可以直接说人话：

> **我**：「标签页太多了，帮我收拾一下，同一个网站的归到一组」
>
> **塔比**：「好嘞喵！帮你把 23 个标签页按域名分成了 6 组：github.com 一组、知乎一组、文档站一组……分好啦 ✨ 还需要我做什么吗喵？」

> **我**：「把打开超过一天的标签都关了，但 GitHub 的留着」
>
> **塔比**：（列出要关闭的标签）「一共 14 个，GitHub 的 5 个我会保留，确认关闭吗喵？」

> **我**：「这个页面讲了什么？三句话总结」
>
> **塔比**：（读完页面）「好嘞喵！三句话版：① 这是某团队的构建提速实践；② 核心靠缓存复用和并行任务，把 20 分钟压到了 3 分钟；③ 文末给了可以直接抄的配置。要我展开讲吗？」

> **我**：「帮我把这个页面存到书签的「前端」文件夹里」

它会真的去执行：关标签、建分组、读页面、存书签——这些操作都是通过 Chrome 官方 API 完成的，和你手动点击效果一模一样。

> 📷 **【截图 2 位置】整理标签页前后对比（全文最重要的一张图）**
> 截什么：整理前（标签栏挤满）+ 整理后（分组整齐）的对比，两张拼一张图，或上下两张
> 怎么截：先截一个标签页很乱的窗口 → 发「帮我收拾一下，同一个网站的归到一组」→ 执行完再截一次。把这段对话也截进去更有说服力

**主打三件事**：

- **收拾标签页**：批量关闭、去重、按域名分组、排序、固定、找回刚关的——「标签页焦虑」一句话解决；
- **整理书签**：搜索、归档、重命名、批量移动删除、一键收藏当前页——让书签栏恢复到「能找到东西」的状态；
- **代你读页、操作页**：总结、翻译、找内容，以及点击按钮、填表单、选下拉框——理论上你在页面上能做的，它都能代劳。

其余的能力也都是一句话的事：窗口管理、历史记录搜索与清理、下载管理、Cookie 查看清理、页面缩放与字体、深浅色主题、网站权限管理、其它扩展的启用/禁用/卸载，外加截图和录屏。

### 三、效率党的另一副面孔：斜杠指令

对话虽好，但有时候你只想要「快」。所以我做了第二套交互：**34 个斜杠指令**，每个还带短别名。这里挑几个最常用的感受一下：

```
/close-duplicates   关闭重复标签页（别名 /cd）
/find               查找并跳转到标签页（别名 /f）
/group-domain       按域名分组（别名 /gbd）
/bookmark           收藏当前页（别名 /bm）
/screenshot         截图（别名 /shot）
/history            搜历史记录（别名 /hi）
/reopen             恢复刚关闭的标签（别名 /undo）
/clear-cookies      清 Cookie
/record-screen      开始录屏
```

（以上只是节选——完整清单在输入框敲 `/help` 就能看到，敲 `/` 也会弹出自动补全。）

> 📷 **【截图 3 位置】斜杠指令自动补全**
> 截什么：在输入框敲 `/` 之后弹出的指令补全列表
> 怎么截：随便打开一个对话页面，敲一个 `/`，等补全列表弹出后截图

熟练之后，`/cd` 回车清掉重复标签，比鼠标点三次菜单快得多。

**两种模式的分工**：一句话描述需求 → 对话；肌肉记忆的固定操作 → 斜杠。同一个能力，两种入口。

### 四、多步任务：先给方案，你确认，它执行

真正有意思的是复杂任务。比如你说：

> 「帮我整理一下书签，重复的合掉，没分类的归到合适的位置」

这种事一步做不完。塔比会先拆解成一个**执行计划**给你看：

```
1. 读取全部书签树
2. 检测重复书签（同 URL）→ 合并
3. 对未分类书签按标题归入合适的文件夹
4. 汇总报告改动明细
```

**确认之后**它才开始动手，每一步的执行结果实时显示在侧边栏里。AI 不背着你偷偷改你的浏览器——改动之前，你永远是那个点头的人。

> 📷 **【截图 4 位置】任务计划确认卡片**
> 截什么：塔比给出执行计划、等待确认的卡片界面
> 怎么截：发一句「帮我整理一下书签，重复的合掉，没分类的归到合适的位置」，等计划卡片出来后截图（先别点确认）

### 五、隐私：你的数据不经过任何人的服务器

这是我做这个插件时最在意的一点，也是它和大多数 AI 插件的本质区别：

- **没有自有服务器**。所有数据读写都在你的浏览器本地完成；
- **自带 API Key（BYOK）**。在设置里填你自己的 API 地址和密钥（任何 OpenAI 兼容接口都行，也支持 Chrome 内置的 Gemini Nano，不填 Key 也能用基础功能）。AI 请求从你的浏览器直接发给你选的服务商，不经过我；
- **对话记录、截图全部本地存储**（IndexedDB），随时一键清空；
- **代码全部开源**，上面每一条你都可以自己验证。

用大白话说：**我是开发者和维护者，但我不经手你的任何数据。**

> 📷 **【截图 5 位置】设置页（BYOK 配置界面）**
> 截什么：设置面板里的模型配置界面（API 地址 / Key 输入框，Key 打码）
> 怎么截：打开插件的设置抽屉，切到模型配置页截图。这张图是「自带 Key」的直接证据，记得遮住你的 Key

### 六、技术栈与安装

MV3 + Vue 3 + TypeScript，界面支持中/英/德/西四种语言。代码结构干净，欢迎 PR。

**安装方式**：

- Chrome 商店：审核中，过审后补链接（可以 Star 一下仓库等通知）

> 📷 **【截图 6 位置，可选】Chrome 商店页面**
> 截什么：过审后的 Chrome 商店详情页
> 怎么截：过审上架后截，放在这里替代「审核中」那一行，链接也一并补上

- 从源码构建：

```bash
git clone https://github.com/codeZF907523110/chromeAIManager.git
cd chromeAIManager
pnpm install
pnpm build
```

然后打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `dist` 目录。

装好后，在设置里填一个 OpenAI 兼容的 API 地址和 Key（或者选 Gemini Nano 白嫖本地模型），就可以开始使唤塔比了。

### 七、接下来要做什么

下一版规划中的功能（按优先级）：

- **划词即问**：选中网页文字，侧边栏直接带着上下文提问
- **跨标签页汇总**：「把这几个标签页的内容对比一下」——AI 逐个读取、综合成报告

- **右键菜单**：选中文字右键直接「问塔比」
