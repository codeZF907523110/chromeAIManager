## 一、测试环境准备

### 1. 加载扩展

```bash
# 1. 构建项目
npm run build

# 2. 打开 Chrome 扩展页面
chrome://extensions

# 3. 开启"开发者模式"

# 4. 点击"加载已解压的扩展程序"

# 5. 选择项目中的 dist 目录（或 manifest.json 所在目录）
```

### 2. 打开侧边栏

- 点击扩展图标，打开 Side Panel
- 确认 AI 配置已设置（API Key、模型名称等）

### 3. 验证基础环境

- [ ] Chrome 浏览器版本 ≥ 88
- [ ] 扩展已成功加载并显示图标
- [ ] 侧边栏能正常打开
- [ ] AI 配置已设置（可在设置页面验证）

## 八、常见问题排查

### 问题 1：提示"该操作我无法执行"

**原因**：agentLoop 的 toolName allowlist 没有包含 `page_` 前缀

**解决**：
检查 `src/composables/useAIEngine.ts` 中是否添加了 `actionStr.startsWith('page_')`

```typescript
// 应该包含这一行
actionStr.startsWith('page_') ||
```

---

### 问题 2：只显示 block 组件，没有 AI 摘要

**原因**：LLM 调用失败

**解决**：
- 检查 API Key 是否有效
- 检查网络连接
- 查看浏览器 Console 错误日志（F12 → Console）
- 检查是否触发了降级逻辑

---

### 问题 3：采集时间过长

**原因**：页面 DOM 节点超过 5000

**解决**：
- 正常现象，会自动截断并提示
- 可以在控制台查看采集耗时

---

### 问题 4：结果不准确

**原因**：页面结构复杂，SPA 动态渲染

**解决**：
- 等待页面完全加载后再测试
- 对于无限滚动页面，只采集可见区域
- 可以多次测试观察一致性

---

### 问题 5：链接无法点击

**原因**：可能是被 CSS 遮挡或事件冒泡问题

**解决**：
- 检查 Block 组件的 z-index
