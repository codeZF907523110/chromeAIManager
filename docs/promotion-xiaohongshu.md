## 一、小红书爆款公式（为什么这么写）

1. **标题 ≤ 20 字，必带情绪或数字**：痛点前置 + 反差感；「求求了 / 救命 / 谁懂」是站内高点击句式
2. **封面决定 80% 点击**：Before/After 对比图 > 大字报 > 纯截图；首图文字 ≤ 10 字
3. **正文 = 钩子 → 共鸣 → 分点干货 → 转化钩子**：前 2 行留不住人就划走了
4. **每 2-3 行一个 emoji 断行**：手机阅读密度，大段文字没人看
5. **文末必带互动引导**：评论权重是小红书流量分发核心指标
6. **标签 6-10 个**：大流量词（#效率工具）+ 精准词（#Chrome插件）混搭

## 四、发布与运营策略

| 项 | 建议 |
|---|---|
| 发布时间 | 工作日 12:00-13:00 / 18:00-22:00；周末 10:00-12:00 |
| 频率 | 两篇间隔 3-5 天，别同天发（被判营销） |
| 置顶评论 | 「Chrome应用商店搜 xxx / 链接见主页」，正文不直接放链接（限流） |
| 评论区 | 前 1 小时秒回；置顶提问式评论（「书签最多的扣1」）拉互动 |
| 流量测试 | 两篇笔记数据对比后，胜出角度追加第三篇（场景细分：学生党版/论文查资料版） |
| 违禁规避 | 不写「最好用/第一」绝对化用语；不放二维码图 |

## 五、内容红线（必守）

1. **截图不得出现 API Key**（历史 key 已在对话中暴露过，截图前重置并打码）
2. 对话截图标注「交互示意」，不虚构不存在的功能
3. 不承诺「永久免费」之类无法保证的话术（模型额度由第三方决定）
4. 收藏/点赞引导可以，「关注领取」类话术避免（诱导限流）
