# 背景粒子星空化（品牌渐变星色 + 发光 + 一闪一闪）

> 状态：已实施（2026-11-20；同日修订：去掉十字光芒，星色统一为品牌渐变三色；
> 二次修订：去掉粒子连线，粒子加密、漂移放缓）
> 背景：ParticleCanvas 粒子用 `--app-text-muted`（#888 灰）、透明度 0.1–0.6 缓慢均匀
> 呼吸——整体偏暗，且没有「星星」的感觉。用户要求：换颜色、每个点像星星一样发光、
> 一闪一闪；随后追加：不要十字光芒，只保留光晕，颜色与品牌图标渐变一致；
> 再追加：不要连线、粒子多一些、移动慢一些。

## 1. 业界做法

Canvas 星空的标准做法（各家 hero 区星空背景通用）：

1. **星色**——从品牌渐变取色（本项目：header sparkle 图标的 青→蓝→紫 渐变），
   整片星域即呈现品牌色；
2. **发光**——`ctx.shadowBlur` + `shadowColor` 同色光晕，亮时光晕增强；
3. **闪烁**——每颗星独立相位/周期的正弦亮度曲线（异步闪烁才是「一闪一闪」，
   统一呼吸是「呼吸灯」）。

## 2. 设计参数

| 项              | 暗色主题                                   | 亮色主题                          |
| --------------- | ------------------------------------------ | --------------------------------- |
| 星色盘          | 品牌渐变三色 #22d3ee / #3b82f6 / #a78bfa（与 header sparkle 图标同渐变，两主题一致，均匀抽取） | 同左                              |
| 亮度曲线        | base 0.5 ± amp 0.4（峰值 ~0.9，谷值 ~0.1） | base 0.35 ± amp 0.25（峰值 ~0.6） |
| 光晕 shadowBlur | 4 + 6×峰值                                 | 3 + 4×峰值                        |

- 闪烁周期：每星随机 speed 0.6–2.2 rad/s（约 3–10s 一闪）+ 随机初相 → 完全异步；
- 星点尺寸 0.8–2px 随机（远近层次）；光晕颜色 = 星色（品牌渐变色）；
- 密度：面积/10000（较原 15000 加密约 50%）；漂移速度 ±0.06 px/帧（较原 ±0.15 放缓）；
- 不做十字衍射光芒（用户明确去掉）；不做粒子连线（用户明确去掉），星空更干净。

性能：粒子数约 30–55（侧边栏面积），shadowBlur 仅作用于粒子绘制；
主题参数按 --app-bg 字符串缓存，不逐帧重算。

## 4. 边界

- 主题切换即时生效（每帧读一次 --app-bg，缓存 key 失效即重算主题参数）。
- 无连线、无十字光芒——只保留发光星点，画面干净。
- 漂移放缓但保留微动（缓慢的太空漂移感），不是完全静止。

## 5. 验证

type-check / eslint / prettier / build 全绿。真机回归：

1. 暗色主题：星点明显变亮，青/蓝/紫品牌色，光晕柔和可见
2. 每颗星异步闪烁（非整体呼吸），无十字光芒、无连线
3. 粒子数量比之前多，漂移明显放缓
4. 亮色主题：星点清晰可见，亮度不过曝
5. 主题切换后亮度参数立即跟随（星色两主题一致）
6. 整体不卡顿
